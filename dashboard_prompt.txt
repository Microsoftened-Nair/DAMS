Specification: Multi-Agent Command Center & Observability Dashboard1. Executive Overview & ObjectivesThe Multi-Agent Command Center & Observability Dashboard is a real-time, feature-rich web platform designed to monitor, inspect, manage, and directly control the autonomous dual-phase multi-agent software engineering framework. It provides complete operational authority—from initiating brand-new software projects directly in the browser to inspecting double-blind cleanroom isolation, tracking AST log sanitization, executing manual human-in-the-loop overrides, and governing Phase 2 GitHub issue/PR maintenance pipelines.Core ObjectivesProject Lifecycle Creation & Management: Launch new software builds directly from the browser, edit live specifications, manage task backlogs, and trigger Phase 1 greenfield builds or Phase 2 maintenance workflows.Full Command & Control: Inject instructions, freeze/resume individual agents, swap LLM models on the fly, force Architect arbitration, trigger manual rollbacks, and override circuit breakers.Real-time Observability: Stream live token usage, execution states, tool calls, stdout/stderr, and context fill levels across all 6 agent roles.Phase Isolation Verification: Audit the double-blind boundary between Coder and Tester, verify AST log sanitization, and display visual QA diffs with bounding box DOM collision calculations.Deterministic Safety Invariants: Monitor safety guardrails ($\Delta \text{Tests} \ge 0$, diff size $<500$ lines) with manual human-in-the-loop intervention controls.2.
